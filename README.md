 **Project Description:**
The Web-Based Document Request and Tracking System for Bahay Pare Elementary School is a proposed responsive front-end web application designed to provide a more organized and user-friendly way of handling school document requests. It focuses on commonly requested documents such as certifications, Form 137, SF10, and other school forms.

The system allows users to view available documents, log in through a front-end interface, submit requests using a structured form, and track the status and details of their requests. It uses mock sample data to demonstrate the user flow and functionality. Since the project focuses on front-end development, it does not include a backend, database, or permanent data storage.

The project aims to provide a clearer and more organized interface for submitting and monitoring school document requests.

**Setup Instructions**

1. Download or clone this repository to your computer.
2. Open the project folder in a code editor (e.g., Visual Studio Code).
3. Make sure the "Live Server" extension is installed in VS Code.
4. Right-click on index.html and select "Open with Live Server" to launch the website.
5. The site will open automatically in your default browser.
